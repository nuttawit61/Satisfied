# สรุปผลความพึงพอใจผู้บริจาคเลือด ปีงบประมาณ 2569

หน้าสรุปผลแบบประเมินความพึงพอใจของผู้บริจาคเลือด ศูนย์รับบริจาคเลือดศิริราช (ห้องรับบริจาคเลือด)

## วิธีเปิดดู
เปิดไฟล์ `index.html` ด้วย Chrome หรือ Edge แล้วใส่รหัสผ่าน (ขอรหัสผ่านจากผู้ดูแล)

ข้อมูลผู้ตอบถูกเข้ารหัสด้วย AES-256-GCM จากรหัสผ่าน (PBKDF2-SHA256 310,000 รอบ) ไม่มีรหัสผ่านเก็บอยู่ในไฟล์
ผู้ที่ไม่มีรหัสผ่านจะอ่านข้อมูลไม่ได้ แม้เปิดดู source code
หลังเข้าสู่ระบบ จะจำไว้จนกว่าจะปิดแท็บ หรือกด "ออกจากระบบ"

## ความสามารถ
- เลือกช่วงเวลา: ทั้งปีงบ 2569 · รอบที่ 1 (ต.ค. 68 – มี.ค. 69) · รอบที่ 2 (เม.ย. – ก.ย. 69) · กำหนดวันที่เอง
- นับตามวันที่ตอบแบบประเมิน หรือวันที่บริจาคเลือด (ปรับแก้ปี พ.ศ./พิมพ์ผิดแล้ว)
- แท็บ สรุปผล / ข้อติชม-เสนอแนะ / ข้อมูลดิบ
- Export Excel (6 ชีต) และ Export PDF (ผ่านหน้าพิมพ์ → บันทึกเป็น PDF)

## โครงสร้าง
```
index.html          หน้าสรุปผล (ไฟล์เดียวจบ)
data/*.xlsx         ข้อมูลต้นฉบับจาก Google Forms (ไม่อัปขึ้น GitHub — อยู่ใน .gitignore)
src/template.html   ต้นแบบหน้าเว็บ
src/prep.py         ทำความสะอาดข้อมูล → JSON
src/build.py        สร้าง index.html ใหม่
src/assets/          โลโก้ภาควิชา (ตัดจากไฟล์ Logo ภาควิชา_TH_แนวตั้ง_2White.png)
src/xlsx.full.min.js  SheetJS 0.18.5 (Apache-2.0)
```

## อัปเดตข้อมูล
```
pip install pandas openpyxl cryptography
python src/build.py "data/ชื่อไฟล์ใหม่.xlsx" --password รหัสผ่าน
```

> เปลี่ยนรหัสผ่านได้โดยรัน build ใหม่ด้วยรหัสผ่านใหม่
> แนะนำให้เก็บ repository เป็น **Private** อยู่ดี เพื่อความปลอดภัยอีกชั้น
